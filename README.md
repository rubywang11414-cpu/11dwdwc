# 投資損益記錄（台股）

可安裝到手機的 PWA，資料只存在你自己的裝置上。

## 部署到 GitHub Pages
1. 到 GitHub 建立新 repository（例如 `invest-tracker`），設為 Public（免費版 Pages 需要公開 repo；程式碼裡沒有任何個人資料）。
2. 把這個資料夾裡的所有檔案（`index.html`、`manifest.webmanifest`、`sw.js`、`icons/`）上傳到 repo 根目錄。
3. 進入 repo 的 Settings → Pages，Source 選 `Deploy from a branch`，Branch 選 `main`，資料夾選 `/ (root)`，按 Save。
4. 約一兩分鐘後，網址會是 `https://你的帳號.github.io/invest-tracker/`。

## 安裝到手機
- iPhone：用 Safari 開啟網址 → 分享 → 加入主畫面。
- Android：用 Chrome 開啟網址 → 選單 → 安裝應用程式（或加到主畫面）。

## 備份
資料存在手機瀏覽器內，請定期在頁面中按「匯出備份」。換手機時在新裝置按「匯入備份」即可。
